# Sistema de Gestión de Tienda (Full Stack)

Aplicación web completa (Full Stack) desarrollada para la administración de inventario y productos de una tienda. Consta de un servidor backend basado en una API REST y una interfaz frontend dinámica.

## Tecnologías Utilizadas

### Backend
*   **Node.js**
*   **Express.js** (Framework para el servidor y manejo de rutas)
*   **MySQL2** (Conector para la base de datos relacional)
*   **CORS** (Para habilitar el intercambio de recursos entre orígenes)

### Frontend
*   **HTML5**
*   **CSS3 / Estilos personalizados**
*   **Bootstrap 5.3** (Framework CSS responsivo)
*   **JavaScript (ES6+) / Fetch API** (Consumo asíncrono de la API)
*   **Google Fonts** (*Poppins*, *Roboto*, *Quicksand*)
